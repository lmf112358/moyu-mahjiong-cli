# 摸鱼雀 CLI

在终端里打日本麻将。支持四人麻将、雀魂式三人麻将、单机 AI 和本地局域网联机，适合程序员低调摸鱼。

当前版本：**v0.8.2**

## 功能

- 四人麻将与三人麻将（移除二万至八万、支持拔北）。
- 东风战、半庄战。
- 单机 AI 对局。
- 本地局域网房间，可由 AI 补足空位。
- 吃、碰、明杠、暗杠、立直、荣和、自摸、振听和多人荣和。
- 宝牌、里宝牌、红宝牌（赤五万/筒/索），本场、供托、亲家与子家点数结算。
- 牌山与王牌区剩余进度条；正常模式下宝牌按颜色区分（表宝牌浅黄、里宝牌浅紫、红五红色）。
- 和牌结算页：显示牌型、役种、翻数、符数、满贯等级和各家点数变化。
- 两种终端牌面，可由每位联机玩家独立选择。

## 下载与运行

Windows 用户可从 [Releases](https://github.com/lmf112358/moyu-mahjiong-cli/releases) 下载 `moyu-majiang-windows-amd64.exe`，在 PowerShell 或 Windows Terminal 中运行：

```powershell
.\moyu-majiang-windows-amd64.exe
```

也可以从源码运行，需要 Go 1.26 或更高版本：

```powershell
go run ./cmd/majiang
```

## 显示模式

启动时可选择：

1. **隐匿模式**：`一/1/①` 分别表示万子、条子、筒子；无颜色、无装饰，采用紧凑等宽布局。
2. **正常模式**：使用放大的多行牌块显示牌面数字与花色，不依赖终端对 Unicode 麻将字符的字体支持。

命令行可用 `--display stealth` 或 `--display normal` 跳过询问。两种模式都会显示所有玩家的舍牌与副露。

## 单机游戏

```powershell
# 四人东风战
go run ./cmd/majiang play --players 4 --rounds 1 --name 摸鱼人

# 三人半庄战，使用隐匿模式
go run ./cmd/majiang play --players 3 --rounds 2 --display stealth --name 摸鱼人
```

参数：

- `--players 3|4`：玩家人数。
- `--rounds 1|2`：`1` 为东风战，`2` 为半庄。
- `--display stealth|normal`：牌面模式。
- `--name 昵称`：玩家昵称。

## 局域网联机

房主创建房间：

```powershell
go run ./cmd/majiang host --players 4 --humans 2 --port 18888 --name 房主
```

同一局域网内的其他玩家加入：

```powershell
go run ./cmd/majiang join --addr 192.168.1.20:18888 --name 同事A
```

房主是权威规则服务器。客户端只收到自己的暗牌和可选操作，不会收到其他玩家的未公开手牌；和牌后会同步显示结构化结算页。请确保系统防火墙允许房主使用所选 TCP 端口。

## 操作

### 隐匿模式

- 输入手牌下方的两位数字出牌，例如输入 `09` 打出第九张牌。
- 特殊操作使用 `[A]`、`[B]` 等字母键，避免与手牌编号冲突。
- 河牌每行六张，`>` 标记最近一张舍牌。
- 听牌时显示可立直的切牌；若不能立直，会说明明副露或点数不足等原因。

### 通用操作

- `a`：自动选择普通出牌。
- `h`：显示帮助。
- `q`：安全退出当前牌局。
- 和牌结算后按 Enter 进入下一局。

## 和牌与计分

已实现的常见役种包括：

- 立直、一发、门前清自摸和、断幺九、役牌、平和、一杯口。
- 七对子、对对和、三暗刻、混老头、小三元。
- 三色同顺、一气通贯、混一色、清一色。
- 岭上开花、海底摸月、河底捞鱼、抢杠。
- 国士无双、四暗刻、大三元、小四喜、大四喜、字一色、清老头。

点数按日麻符翻计算，区分荣和、自摸、亲家、子家，并处理满贯、跳满、倍满、三倍满和役满。结算页逐项显示役种翻数、符数、宝牌/里宝牌、拔北、实际得点与所有玩家的点数变化。

## 当前限制

这是首个公开版本，尚未完整覆盖雀魂全部边界规则，例如九种九牌、四风连打、四杠散了、四家立直、责任支付，以及部分复合役满和抢加杠流程。若用于正式竞技，请以雀魂官方规则和牌谱裁定为准。

## 开源参考

听牌算法测试参考了 [Poker-sang/Mahjong](https://github.com/Poker-sang/Mahjong) 的分类剪枝思路与示例牌型。本项目使用枚举34种待牌并进行完整牌型分解的实现，同时对标准型、七对子、国士无双、十三面听和九面听进行测试。
